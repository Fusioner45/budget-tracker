# Budget Tracker

A tiny expense tracker for students, written from scratch in Python.

## Features (v1 — work in progress)

- Terminal menu: add expenses, view totals per category, view general total, list all expenses
- Fixed categories: Courses, Transport, Loyer, Études, Loisirs, Autre

## Run

```
python main.py
```

## Status

Skeleton with stub functions — the menu loop works, features are being implemented.
